# knowledge/leadership

Place **DHL-approved** source documents for the future AI assistant here
(for example Markdown or plain-text lessons, study notes, FAQs).

Rules:
- Only add material DHL leadership has approved.
- Only add material DHL owns or has written permission to use.
  Do not upload copyrighted books without permission.
- Add a short header to each file: title, author, approval date, approved by.

These files are not used by the website yet. A future backend will split
them into passages, index them, and retrieve relevant passages for the
assistant (RAG). See the main README, section 13.
