# knowledge/bible

Bible text for the future AI assistant's retrieval.

Use a **public-domain** translation here (for example the King James
Version or the World English Bible), or a translation whose license
allows this use. Most modern translations (NIV, ESV and many Tagalog and
Korean versions) are copyrighted and need permission from the publisher.

Suggested format: one file per book (e.g. `43-john.md`) with one verse
per line, starting with its reference: `John 3:16 For God so loved...`
Keeping the reference on every line lets the assistant cite exact verses.
