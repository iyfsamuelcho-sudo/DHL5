# knowledge/ock-soo-park

Source material for "Pastor Ock Soo Park's teaching" in DHL AI:

- The Secret of Forgiveness of Sin and Being Born Again
- Who Are You Who Is Dragging Me?
- Teachings concerning the Tabernacle

IMPORTANT: these books are copyrighted.

- Do NOT put the book text in this folder in a PUBLIC GitHub repository.
  Anything in a public repository can be downloaded by anyone.
- Get written permission from the publisher/rights holder before using the
  text in an AI system.
- Store the text privately on the backend (for example in a private
  repository or the backend's own storage), where it is split into short
  passages and indexed for retrieval.
- Tag every passage with its source: book title, chapter and page, so the
  assistant can cite it and keep it separate from Bible text.

The assistant must never present Pastor Park's teaching as a direct
statement of the Bible (see ai/dhl-ai-system-prompt.md, sections 3 and 15).
